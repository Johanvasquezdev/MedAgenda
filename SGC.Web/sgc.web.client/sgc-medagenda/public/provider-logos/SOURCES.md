# Provider logo sources

The following local files preserve source logos for provider identification in the MedAgenda interface. Each mark is displayed with its original proportions and is not presented as an endorsement.

The `feature/` WebP files are display-only derivatives used on the public coverage page. They reduce blank source margins or optimize resolution; they do not redraw, recolor, or distort the official marks. `feature-transparent/` contains display-only copies with the white canvas made transparent. Original source downloads remain alongside them.
